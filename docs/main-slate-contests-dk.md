# NFL main slate contests

DraftKings lobby, classic, all guaranteed. Copied with about 2 hours until the listed start. `K` entry counts are the lobby's rounded figures. Early Only is a different set of games.

Overlay = guaranteed prizes minus entry fees already collected. A positive overlay is money DraftKings still has to add. Cut if full = the house share once every seat is sold.
